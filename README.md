> **Topics Covered:** 19 Fundamental Algorithmic Patterns | 101 Selected Interview Problems

---

## 📌 About This Repository

Instead of blindly grinding hundreds of LeetCode problems, this project focuses on **pattern recognition**. The goal of this repository is to serve as an open study guide for myself and the developer community by documenting:

* **Intuition First:** Breaking down *why* a specific pattern applies.
* **Obsidian Integration:** Fully structured with YAML frontmatter, internal links (`[[Pattern]]`), tags, and Dataview support for seamless note-taking.
* **Dual Approach:** Documenting both brute force and optimal solutions to practice trade-off discussions.
